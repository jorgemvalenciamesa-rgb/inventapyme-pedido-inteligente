# Pedido inteligente de InventaPyme

Demo del componente de inteligencia artificial de **InventaPyme**, una app de inventario para tiendas de barrio
(Saber Conocer, Eje 4 – Fundación Universitaria del Área Andina).

- **Qué hace:** un modelo de machine learning (regresión Ridge entrenada con scikit-learn) pronostica las ventas diarias de cada producto y sugiere cuánto pedir al proveedor, explicando el porqué.
- **Cómo funciona la demo:** el modelo entrenado (coeficientes) viaja dentro de `index.html` y se ejecuta en el navegador, sin servidor y sin internet.
- **Datos:** ventas simuladas de una tienda de ejemplo (Granero Central, Pereira). Deben validarse con datos reales.
